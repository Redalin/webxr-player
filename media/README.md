# Sample Media Directory

Place your 2D and 3D video files in this folder (`./media`).

### Supported 3D Formats & Naming Patterns
- **Side-by-Side (SBS)**: Add `_sbs`, `3dsbs`, or `.sbs.` to the filename (e.g. `avatar_3d_sbs.mp4`)
- **Top-Bottom / Over-Under (TB/OU)**: Add `_tb`, `_ou`, or `3dtb` to the filename (e.g. `movie_3d_tb.mp4`)
- **180° VR (Hemisphere)**: Add `180` or `vr180` to the filename (e.g. `rollercoaster_vr180.mp4`)
- **360° VR (Sphere)**: Add `360` or `vr360` to the filename (e.g. `space_vr360.mp4`)

*Note: You can also manually adjust the 3D mode for any video using the dropdown selector on each video card or in the video player.*
